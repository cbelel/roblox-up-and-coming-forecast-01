A forecaster for Roblox's Up-and-Coming top 10: it reads the chart's hourly history, models each game's expected rank from its recent rank, trend, player growth and volatility, and writes one probabilistic forecast for the 72 hours after entries close.
## Run it
```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
